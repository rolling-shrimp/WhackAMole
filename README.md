# 打地鼠遊戲規格

## 第一部分：遊戲規則

### 遊戲說明

- 遊戲分為第一關與第二關。
- 玩家在第二關失敗後，必須從第一關重新遊玩。

### 第一關規則

- 玩家打中一隻灰色老鼠，增加 1 分。
- 第一關取得 42 分以上即過關。
- 第一關分數未滿 42 分即失敗。

### 第二關規則

- 玩家打中一隻灰色老鼠，增加 1 分。
- 玩家打中一隻棕色倉鼠，增加 3 分。
- 玩家點中一個炸彈，扣除 2 分。
- 第二關取得 52 分以上即闖關成功。
- 第二關分數未滿 52 分即闖關失敗。

## 第二部分：Use Case

### 意圖

身為遊戲玩家，我希望能遊玩可以闖關的打地鼠遊戲，以完成闖關挑戰。

### 第一關開始前

1. 遊戲顯示 4×4 洞口與「開始」按鈕。
2. 遊戲顯示第一關記分板：
   - 第一關分數：0 分。
   - 命中灰色老鼠數量：0。
3. 玩家點擊「開始」按鈕。
4. 遊戲隱藏「開始」按鈕。
5. 遊戲開始 60 秒計時，第一關開始。
6. 第一隻灰色老鼠會立即出現，或於 700 毫秒後出現。

### 第一關

1. 遊戲在 16 個洞口中的一個隨機洞口顯示灰色老鼠。
2. 灰色老鼠顯示 700 毫秒後消失。
3. 玩家在灰色老鼠顯示期間點擊灰色老鼠。
4. 灰色老鼠消失。
5. 遊戲將第一關分數增加 1 分。
6. 遊戲將第一關命中灰色老鼠的數量增加 1。
7. 遊戲更新第一關記分板上的分數及命中灰色老鼠數量。

### 第一關結束後

1. 遊戲停止顯示灰色老鼠。
2. 遊戲顯示第一關分數。
3. 遊戲顯示第一關命中灰色老鼠的數量。

如果玩家取得 42 分以上：

1. 遊戲顯示過關標語。
2. 遊戲顯示「開始」按鈕。

如果玩家取得的分數未滿 42 分：

1. 遊戲顯示 `Game Over`。
2. 遊戲顯示「重玩」按鈕。
3. 玩家點擊「重玩」按鈕。
4. 遊戲清除第一關的分數及命中灰色老鼠數量。
5. 遊戲隱藏「重玩」按鈕。
6. 第一關記分板的資料歸零：
   - 第一關分數：0 分。
   - 命中灰色老鼠數量：0。
7. 遊戲開始 60 秒計時，第一關重新開始。

### 第二關開始前

1. 遊戲隱藏第一關記分板。
2. 遊戲顯示第二關記分板：
   - 第二關分數：0 分。
   - 命中灰色老鼠數量：0。
   - 命中棕色倉鼠數量：0。
   - 點中炸彈數量：0。
3. 玩家點擊「開始」按鈕。
4. 遊戲隱藏「開始」按鈕。
5. 遊戲開始 60 秒計時，第二關開始。

### 第二關

1. 第一個目標為灰色老鼠、棕色倉鼠或炸彈，並且會立即出現，或於 700 毫秒後出現。
2. 遊戲在 16 個洞口中的一個隨機洞口顯示灰色老鼠、棕色倉鼠或炸彈。
3. 灰色老鼠、棕色倉鼠或炸彈顯示 700 毫秒後消失。

玩家點擊灰色老鼠：

1. 灰色老鼠消失。
2. 遊戲將第二關分數增加 1 分。
3. 遊戲將第二關命中灰色老鼠的數量增加 1。

玩家點擊棕色倉鼠：

1. 遊戲將第二關分數增加 3 分。
2. 遊戲將第二關命中棕色倉鼠的數量增加 1。

玩家點擊炸彈：

1. 遊戲將第二關分數扣除 2 分。
2. 遊戲將第二關點中炸彈的數量增加 1。
3. 如果扣分後的分數低於 0，分數維持為 0。

### 第二關結束後

1. 遊戲停止顯示灰色老鼠、棕色倉鼠及炸彈。
2. 遊戲顯示第一關與第二關的分數。
3. 遊戲顯示第一關與第二關各自命中灰色老鼠的數量。
4. 遊戲顯示第二關命中棕色倉鼠的數量。
5. 遊戲顯示第二關點中炸彈的數量。

如果玩家取得 52 分以上：

1. 遊戲顯示闖關成功。
2. 遊戲顯示「重玩」按鈕。

如果玩家取得的分數未滿 52 分：

1. 遊戲顯示 `Game Over`。
2. 遊戲顯示「重玩」按鈕。

玩家選擇重玩：

1. 玩家點擊「重玩」按鈕。
2. 遊戲隱藏「重玩」按鈕。
3. 遊戲清除第一關與第二關的所有分數及命中紀錄。
4. 遊戲顯示第一關記分板：
   - 第一關分數：0 分。
   - 命中灰色老鼠數量：0。
5. 遊戲開始 60 秒計時，第一關重新開始。
